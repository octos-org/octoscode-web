# 中文术语表

界面中文以这张表为准。英文是代码里的源文案（`t("…")` 的 key），中文是 `zh.ts`
和各功能 `*-copy.ts`
里的译文。新增或改动文案前先查这里；表里没有的词，先补进表，再写译文。

缺翻译由 `apps/web/src/features/preferences/zh-coverage.test.ts`
把关，有三种情况会失败：

- `t("…")` 的 key 没有中文；
- `aria-label`、`placeholder`、`title`、`alt` 直接写了英文；
- JSX 里直接写了英文正文。

## 原则

- 对用户说人话：说「这个会话」「这一轮」，不说协议里的名词。
- 一个概念只用一个词。同一屏里不能一边写「工作区写入」，一边写「写入 · 允许联网」。
- 名称原样保留：产品名、模型名、路径、命令名（`/undo`）、用户和模型写的内容都不翻译。
- 读屏和看到的一致：按钮的可访问名称要包含它的可见文字（WCAG 2.5.3）。

## 术语

| 英文                         | 中文                   | 说明                                                               |
| ---------------------------- | ---------------------- | ------------------------------------------------------------------ |
| Session                      | 会话                   | 一次连续的对话和它的工作区。不叫「对话框」                         |
| Conversation                 | 对话                   | 会话里来回的消息；「对话链接」指向某个会话                         |
| Turn                         | 一轮、这一轮、本轮     | 用户发一次消息到 Octos 回完。不用「回合」                          |
| Workspace                    | 工作区                 | 会话所在的文件夹。界面里需要强调是文件夹时，可以说「工作区文件夹」 |
| Steer                        | 插话                   | 在这一轮还在运行时补一句。不用「引导」「转向」                     |
| Queue / queued               | 排队                   | 「排队的消息」「排到这一轮结束后」                                 |
| Peer                         | 协作者                 | 由会话派出、并行工作的另一个智能体。不用「同侪」「对等节点」       |
| Fleet                        | 多智能体               | 协作者的总览页。不用「舰队」                                       |
| Approval                     | 审批                   | 动作本身叫「批准」「拒绝」                                         |
| Permission                   | 权限                   | 档位：只读、工作区写入、写入 · 允许联网                            |
| Plan                         | 计划                   | Octos 列出的步骤清单                                               |
| Trajectory                   | 轨迹                   | 会话里计划和后台工作的总览页                                       |
| Background task              | 后台任务               |                                                                    |
| Output / artifact            | 产物                   | 会话里写出或发给用户的文件                                         |
| Changes                      | 改动                   | 新建、修改、删除；Git 范围写「未提交（Git）」                      |
| Thinking / reasoning         | 思考                   | 折叠条写「思考过程」。字数按字计：中文一个汉字算一个               |
| Model                        | 模型                   | 模型名原样保留                                                     |
| Provider                     | 提供商                 |                                                                    |
| Profile                      | 配置档案               | 尽量不出现。能说「这个服务器的默认模型」的地方就不提它             |
| Skill                        | 技能                   |                                                                    |
| Server                       | 服务器                 | 用户连接的 Octos。不写「Core」「内核」                             |
| Auth token                   | 访问令牌               |                                                                    |
| token（计量单位）            | token                  | 模型用量的单位，保留英文                                           |
| Draft                        | 草稿                   |                                                                    |
| Diagnostics                  | 诊断信息               |                                                                    |
| Theme: System / Dark / Light | 跟随系统 / 深色 / 浅色 |                                                                    |

## 语气

- 句子短，先说结果，再说下一步。例如：「没能复制。请选中代码手动复制，或者重试。」
- 报错说清楚出了什么问题、用户能做什么，不甩锅给用户。
- 中文标点用全角；数字、单位和英文名称前后各留一个空格（「20
  MiB」「Octos 服务器」）。
